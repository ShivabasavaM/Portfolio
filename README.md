## ✨ About This Portfolio

This repository isn't just a static document; it is built as a highly optimized, interactive web product showcasing my engineering capabilities. 

### Key Features:
* **🤖 Live Agentic RAG Chatbot:** Integrated with a custom FastAPI backend, allowing recruiters to chat with an AI assistant that has complete context of my resume and projects via Server-Sent Events (SSE) streaming.
* **🎬 Cinematic 3D Carousel:** A mathematically calculated 3D perspective slider for rendering project cards with auto-playing video integration and glassmorphic UI.
* **🧲 Full-Page Scroll Snapping:** Apple-style `100vh` scroll snapping architecture paired with `IntersectionObserver` for precisely timed, staggered content reveals.
* **🛡️ Pre-flight Guardrails:** Client-side word-count limiters and adversarial prompt detection built directly into the UI layer.

## 🛠️ Tech Stack (Portfolio Frontend)
* **Framework:** React + Vite
* **Styling:** Custom CSS (Glassmorphism, CSS Animations, Flexbox/Grid)
* **State Management:** React Hooks (`useState`, `useEffect`, `useRef`, `useCallback`)
* **Backend Connection:** Native `fetch()` API with TextDecoder for parsing `text/event-stream` chunks.

## 💻 Featured Systems Showcased
1. **Aegis-Audit:** Agentic RAG legal compliance engine (React, FastAPI, Pinecone, LlamaParse).
2. **Metabolic Health Coach:** Biometric orchestration pipeline (LangGraph, Fitbit OAuth2, Gemini Vision).
3. **Rescue AI Triage:** PyTorch MobileNetV3 canine injury classifier on AWS.
4. **0xGuard NIDS:** Isolation Forest network anomaly detection engine.
